口径说明

  • 后端执行：从后端 attempt 开始到 attempt 完成的执行区间；实体瓦片已由 Worker 生成并上传，输出索引/格网记录随后通过 OpenGauss 完成写出。
  • 端到端：从 API 提交开始到任务最终完成，包含 API、排队、Ray Job 启动、driver、Worker、输出写入和状态轮询。
  • worker task 结果：实际返回实体处理结果的 Ray task 数；不是预热 worker pod 数。一个 task 可以在同一 asset 内处理多个 cell。
  • 五轮统计使用全部五个有效样本，不用“是否小于 10 秒”反向筛选平均值；早期出现过的远程调度异常长尾不属于本五轮样本，原始记录仍保留在临时测试目录。

优化内容

  • 同一 asset 的实体格网覆盖结果只计算一次，后续单元复用缓存。
  • 覆盖 cell 按唯一空间 shard 分配，避免重叠 shard 重复执行掩膜、写瓦片和 MinIO 检查。
  • 同一数据集的实体单元共用一个 batch driver，一次性提交并批量等待 Ray task，减少重复 Ray Job 初始化。
  • 小范围 AOI 使用 ISEA4H 邻域遍历路径，避免为完整 level-6 全球 cell 集合建立不必要的空间索引。
