### 1.2 明确不负责什么

- **不做格网编码、拓扑与坐标映射**。`geohash`/`mgrs`/`isea4h` 的定位与编码在 ⑥（`cube_encoder`）；
  本子系统只把前端选择映射为 Cube v3 的 `grid_type`（`backend/api/search.py:38`–`:42`）。
- **不做剖分计算与 `partition_*` 表写入**。表由 ②（`cube_split`/`cube_web`）写入，
  本子系统只读 `partition_tiles`/`partition_grid_cells`/`partition_datasets`/`partition_dataset_assets`
  （`backend/api/search.py:495`–`:505`、`backend/services/cube_v3_compute.py:485`–`:515`）。
- **不做作业调度、配额与执行器选择**。`compute_jobs` 队列、CPU 配额、K8s Job/RayJob 全部在 ④（资源调度），
  见 T4 手册第 1.1 节；本子系统只负责**提交前的输入归一化与提交入口**。
- **不做审计与后台管理**。治理配额表虽被本子系统调用（`enforce_governance_action`），
  但治理与审计归 ⑤（后台管理）。

### 1.4 与其它 5 个子系统的边界（各一句话）

- **① ARD 数据载入**：负责把原始卫星数据搬进 MinIO 并登记场景；T3 只在物化/计算时**读**这些对象。
- **② 分析就绪数据剖分**：负责生成 `partition_*` 权威瓦片；T3 **只读**，不写。
- **④ 资源调度**：负责作业排队与容器执行；T3 只提供提交入口与输入清单。
- **⑤ 后台管理**：负责用户、角色、配额策略、审计；T3 调用它的 `enforce_governance_action` 做闸门。
- **⑥ 全球离散格网模型与编码**：负责格网算法；T3 通过 `grid_type` 字符串与之解耦。

### 4.3 瓦片预览接口

## 8. 关键业务流程

### 8.1 主流程 A：交互式时空检索（SERV-003/004/005）

1. 前端在 `SearchPanel.vue:133` 选择「六边形/经纬度/平面瓦片」，得到 `coordinate_system`

2. 用户在 `MapView.vue:759/873` 框选或多边形绘制，或直接点选；`SearchPanel.vue:520`–`:521`
   （`submitSearch` 内 `emit('search', buildSearchPayload())`；`:241` 只是 `defineEmits` 声明）
   交由 `App.vue:2931 handleSearch`。
3. `App.vue:1469` 调 `searchByPolygon`，或 `App.vue:1483` 调 `searchByBbox`
   （点选场景走 `App.vue:1471` 的极小 bbox 转换）。
4. 后端 `spatial_search`（`search.py:1526`）先过治理闸门（`search.py:1511`），
   再进 `_execute_spatial_search`（`search.py:1456`）。
5. `_grid_type_for_coordinate_system`（`search.py:324`）把坐标系映射为 `grid_type`；
   未选坐标系直接 400。
6. `_query_cube_v3_available_levels`（`search.py:596`）取 bbox 内可用层级；
   `_preferred_partition_levels`（`search.py:343`）按与请求 `resolution` 的接近度排序。
7. 按传感器分组逐层级调用 `_query_cube_v3_partition_grid_assets`（`search.py:400`）；
   SQL 固定过滤 `pt.status='ready' AND pt.publication_status='published'`（`search.py:425`），
   按 `DISTINCT ON (pt.space_code, pt.dataset_id)` 去重，`sr_band1` 优先（`search.py:507`）。
8. Python 侧二次过滤：客户端多边形用 `_geometry_intersects_polygon`（`search.py:831`）做精确相交，
   不通过则丢弃（`search.py:546`–`:547`）。
9. 组装 `items[]` 与 `tile_layer`（`search.py:553`），返回；`search.py:1493`
   按命中数上报 `SpatialSearchTileRead`。
10. 前端 `App.vue:1516` `searchResults.value = buildSceneRows(spatialItems)`，
    结果卡片渲染在 `DownloadPanel.vue`；勾选后 `已勾选格网 N 个`（`DownloadPanel.vue:13`）。

### 8.2 主流程 B：查询结果保存为数据包并下载（SERV-006）

1. 前端 `App.vue:3455` 调 `materializeGridSelection()`（`frontend/src/services/api.js:153`），
   载荷含 `grid_ids`、`scene_ids`、`tile_refs`、`resolved_snapshot`、`dataset_groups`、`metadata`。
2. `POST /api/compute/grid-selections/materialize`（`compute.py:2734`）过治理闸门、
   解析资源身份，写一条 `compute_jobs`（`operator=grid_selection_materialize`，
   `output_format=file`，`skip_map_publish=True`，`job_category=export`，`queue_name=batch_compute`）。
3. 消费 `jobs_per_day` 配额（`compute.py:2781`）并返回 `{"job": ..., "job_id": ...}`。
4. ④ 的 worker 领取后走 `compute_worker.py:1475` 分支 →
   `execute_tile_package_materialize_job`（`tile_package_materialize.py:579`）。
5. 该函数调 `build_direct_entries`（`cube_v3_compute.py:460`）取源 URI。`build_direct_entries` 的
   WHERE（`cube_v3_compute.py:520`–`:527`）为：`{group_filter}`、`{tile_filter}`、`{dataset_filter}`、
   `{band_filter}`、`pt.status = 'ready'`（`:524`）、`pd.partition_status IN ('completed','running')`（`:525`）、
   `pgc.geometry IS NOT NULL`（`:526`）、`{source_uri_sql} IS NOT NULL`（`:527`）；非 `/cog/` 源在
   Python 侧由 `_is_legacy_cog_uri` 剔除（`:547`）。**该 SQL 没有 `publication_status` 谓词**（`grep -c publication_status` = 0）。
6. `_build_materialized_tile_package_at`（`tile_package_materialize.py:254`）逐个瓦片
   按几何裁剪每个波段为 `tiles/<tile_id>/<band>.tif`，写包内 `manifest.json`
   （含 `tile_count`、`grid_count`、`tile_refs`、`band_codes`、`scene_ids`、`tiles[]`、`files[]` 摘要、
   `manifest_sha256`），登记为个人空间 `tile_package` 资产。
7. 前端 `App.vue:3472 waitForGridMaterializeJob` 轮询 `getComputeJob(jobId)` 直到 `SUCCEEDED`。
8. 用户在个人空间选中包 → `downloadWorkspaceAssetPackage`（`api.js:99`）→
   `GET /api/workspace/assets/{id}/download`（`user_workspace.py:3451`）：
   先 `create_download_order`（`user_workspace.py:3475`）、`mark_download_order_processing`、
   打 ZIP、扣减 `exports_per_day` 与 `export_bytes_per_day` 配额，最后
   `add_download_order_items` + `mark_download_order_completed`（`user_workspace.py:3511`）。
9. 订单写失败时只记 warning 并把订单标失败，**不影响 ZIP 下载**
   （`user_workspace.py:3519`；同类策略见 `download.py:101`）。

1. 前端 `ComputePanel.vue:155` 打开提交对话框（`openSubmitDialog('batch')`），

   `build_operator_execution_plan`（`operator_execution_plan.py`）、
   `_attach_step_manifest`（`compute.py:2110`）。
4. `build_step_manifest`（`step_manifest.py:66`）生成 `version=2` 的不可变清单并附 `sha256`；
   worker 侧用 `is_valid_step_manifest`（`step_manifest.py:133`）校验，
   篡改即 `ValueError("Compute step manifest is invalid")`（`compute_worker.py:1446`）。
5. 三个导出型算子由本子系统 worker 直接在分发点执行：`compute_worker.py:1461`
