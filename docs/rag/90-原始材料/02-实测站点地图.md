# 实测站点地图与路由证据

本文件记录 2026-09-12 用真实 Chromium（Playwright）登录三套运行实例后逐页点击所得的**第一手实测结果**。
这是操作手册章节划分与技术人员理解部署拓扑的依据。凡与代码不一致处，以代码为准并在手册中标注。

测量方式：`tools/sitemap2.py`、`tools/sitemap165.py`，账号 `admin`（管理员角色）。
所有操作均为只读浏览，未修改任何服务端数据。

## 1. 三套实例与统一登录

| 实例 | 地址 | 承担子系统 | 登录入口 |
| --- | --- | --- | --- |
| poufennode01（本机） | `http://10.3.100.179:50040` | ② 分析就绪数据剖分、⑥ 全球离散格网模型与编码 | 访问即跳转 `.182:5177/login` |
| poufennode04 | `http://10.3.100.182:5177` | ① ARD数据载入、⑤ 后台管理 | `/login`（**同时是全系统登录页的提供方**） |
| gmhnode04 | `http://10.3.100.165:5176` | ③ 剖分数据服务、④ 资源调度 | 落地页「登录」按钮 → 跳转 `.182:5177/login` |

**关键事实：三套实例共用一套 NODA 单点登录，登录页由 `10.3.100.182:5177` 提供。**
跳转形如：

```
http://10.3.100.182:5177/login?client_id=<客户端标识>&redirect_uri=<回跳地址>/callback&state=<随机串>
        ↓ 提交账号密码与角色
http://<回跳主机>/callback?target=<目标路由>&code=<一次性授权码>&state=<随机串>
```

实测到的 `client_id`：`.182` 自身与 `.179:50040` 使用 `system_ard`；`.165:5176` 使用 `system_src_me`。
登录页可选角色 5 种：普通用户 / 高级用户 / 科学家团队 / 操作员 / 管理员。

## 3. 各子系统页面与子标签（实测）

### ① ARD数据载入（`.182:5177/ard`）

- 一级标签：`ARD数据接入` ｜ `多源遥感元数据信息提取`
- 载入配置控制台：
  - 远程清单定时监听（轮询间隔（分钟）可填，`启动监听` 按钮，状态徽标「已停止/运行中」）
  - 离线导入（`点击选择本地清单文件 (.excel)` + `确认导入`）
- 批次清单动态：搜索框、`全部卫星来源` 下拉、`显示所有数据` 复选
  - 表头：批次号 / 数据类型 / 元数据提取 / 载入状态 / 推送状态 / 订单数 / 加载时间 / 操作
- 批次处理进度（共享存储 → COG/元数据 → 用户 MinIO）
- 指标：总批次 / 通过率 / 失败 / 光学数据(n) / 碳卫星产品(n) / 雷达数据(n) / 信息产品(n)
- 右栏：核验审计日志（实时滚动，含 `[CUBE_SYNC]`、`[CUBE_SYNC_FAILED]` 等条目）
